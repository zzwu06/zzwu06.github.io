Dimensionality Reduction and Phase Plane Analysis

Will the neuron return to rest?

A two-variable model represents a neuron's state as one point. Its coordinates are voltage u and a recovery variable w. The arrows show how that point moves. On each nullcline, one coordinate stops changing instantaneously. Where the two lines cross, both stop changing, so the crossing is a fixed point.

Change a to rotate the voltage nullcline and watch how the trajectory changes. Click or tap the plot to start elsewhere. With the plot focused, use the arrow keys to move the starting point.

Model equations

This example uses the linear system in the textbook's phase-plane section. The recovery equation holds b = 1 and ε = 0.30 fixed.

dudt=au−w dwdt=ε(bu−w)

Setting each derivative to zero gives w = au and w = bu. The voltage equation describes motion along the horizontal axis. The recovery equation describes motion along the vertical axis.
